# Описание пакетов данных

## SessionMetadata

Передаётся в начале сессии. Содержит ID сессии, роль устройства, ID автомобиля, версию протокола, версию прошивки и служебные теги.

## DeviceConfig

Композитная конфигурация устройства. Может передаваться одним блоком или отдельными блоками `AudioConfig`, `ImuConfig`, `CanConfig`, `GpsConfig`, `VehicleConfig`.

## AudioConfig

Описывает аудиопоток:

- частоту дискретизации;
- формат сэмпла;
- количество каналов;
- размер аудиоблока;
- layout: interleaved/planar;
- карту каналов и геометрию микрофонов.

## AudioBlock

Содержит аудиоблок и временной диапазон `t0_ns..t1_ns`.

Правило времени: `t0_ns` — время первого аудиофрейма блока. Время любого сэмпла восстанавливается по `sample_rate_hz` и индексу frame внутри блока.

## ImuConfig

Описывает LSM6DS3:

- интерфейс SPI;
- режим FIFO/DMA;
- ODR;
- размер окна;
- диапазон акселерометра;
- диапазон гироскопа;
- ориентацию датчика на кузове.

## ImuWindow

Содержит агрегированное окно IMU:

- среднее ускорение;
- среднюю угловую скорость;
- интегральное приращение скорости;
- интегральное приращение угла;
- количество сэмплов;
- флаги качества.

## CanConfig

Описывает жёстко заданные CAN-сигналы:

- CAN ID;
- start bit;
- bit length;
- byte order;
- scale/offset;
- роль сигнала: скорость, АКПП, угол руля.

## CanDecodedValue

Декодированное значение CAN-сигнала. Минимальный набор для MDF4:

- `t_ns`;
- `value_id`;
- `can_id`;
- `value`;
- `raw_value`;
- `flags`.

## CanRawFrame

Сырой CAN-фрейм. Нужен для отладки, проверки декодера и возможного пересчёта offline.

## TrajectoryPoint

Точка локальной траектории:

- позиция;
- скорость;
- yaw/pitch/roll;
- yaw rate;
- пройденный путь;
- скорость автомобиля;
- флаги качества.

## GpsFix

Внешний GPS/RTK fix:

- координаты;
- высота;
- скорость;
- heading;
- точность;
- тип фиксации;
- количество спутников.

## TimeStatus

Статус временной базы и синхронизации.

## SystemStatus

Статус подсистем ADSP-SC589: audio, CAN, IMU, GPS, network, overruns, errors, CPU load.

## ImuCalibrationEvent

Событие обновления IMU-калибровки во время стоянки.

## SessionEnd

Финальный пакет сессии.
